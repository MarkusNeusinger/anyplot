# A wrong plot is fixed in its spec or a rule and regenerated, not patched by hand

- Date: 2026-11-18
- Proposed: the README's earlier, absolute highlight "No generated plot is patched by hand", which
  did not hold: the palette swap of May 2026 had edited the plots' code across the catalogue.
- Decided: recorded on 2026-11-18, among the README's six decisions, whose reader-facing sentences he
  chose: a wrong plot is fixed in its spec or in a rule and then regenerated, not patched by hand,
  and a fix to a prompt or a spec reaches every plot it governs at that plot's next regeneration.
