# A search text is kept 180 days, every text alike

- Date: 2026-11-18
- Proposed: the list was built with 90 days, and a shorter period for texts searched only once was
  on the table.
- Decided: 180 days for every text, the period the machine reads and the chat's telemetry already
  have, so the site has one number to state and to keep. A hand-made database snapshot leaves the
  table's rows out, because a snapshot is never deleted.
