# A GitHub release is the changelog section condensed, never copied

- Date: 2026-08-28
- Proposed: the release page of v3.1.0 was the whole changelog section, copied: 640 lines.
- Decided: a release page has an intro line, the section's own headings, one bullet of at most two
  lines per notable entry, and a compare link; numbers are copied exactly, and the full text lives
  only in the changelog. The wording of the rule is his, taken over from the rule the sibling project
  kurrentschrift set that day.
