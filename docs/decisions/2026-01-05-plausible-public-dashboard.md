# Plausible for analytics, with a dashboard anyone can see

- Date: 2026-01-05
- Proposed: Google's analytics, which in his words focuses much more on the visitors themselves.
- Decided: recorded by 2026-01-05: Plausible counts the site's visits and events, with no cookies for
  visitors. Its dashboard is public and linked from the README by 2026-04-14; the analytics reference
  adds that every event is therefore one a reader from outside understands. He confirmed it as his
  decision on 2026-11-19. His reason, given that day: he likes statistics, so it mattered to him that
  the site uses Plausible instead of Google's version, and that the dashboard is public, so anyone
  can see the stats.
