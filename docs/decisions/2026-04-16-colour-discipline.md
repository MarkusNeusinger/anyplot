# The brand green is rare, so a plot's colours land with full impact

- Date: 2026-04-16
- Proposed: a website that uses the palette's colours liberally, which the style guide warns would
  cost the plots their punch.
- Decided: the brand green `#009E73` appears only in a few deliberate places; the rest of the site is
  warm grey on a warm off-white instead of pure white, so a plot's colours land with full impact.
  Written into the style guide on 2026-04-16. He confirmed it as his decision on 2026-11-19.
