# What the user chose stays the user's choice

- Date: 2026-11-04
- Proposed: a new binder rule kept a lower and an upper bound column from being bound the wrong way
  round.
- Decided: a pair the user binds that way by hand stays valid and nothing blocks the confirmation,
  because a person may do it on purpose. On 2026-11-13 he decided two more of the kind: a colour the
  user names is the user's choice, and where a plot needs one value per category the chat asks
  whether to sum or average instead of taking a mean nobody chose; in a persona round, two of three
  users with such data had meant the sum.
