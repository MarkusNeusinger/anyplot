# Each library joins in the language in which it is used most

- Date: 2026-05-07
- Proposed: a catalogue of Python libraries only, nine at the 1.0.0 launch, with Highcharts through
  its Python wrapper.
- Decided: the library-expansion roadmap of 2026-05-07 set the rules: a language needs code-driven
  plots, a free toolchain and a public package registry; a library appears once, under the variant
  with at least three times the weekly downloads of every other, else the native one; free and
  open-source libraries come first. R and ggplot2 followed in release 2.4.0 (2026-05-18), and Julia
  with Makie and JavaScript with Chart.js, D3, ECharts and MUI X in 3.0.0 (2026-06-10), when
  Highcharts moved to native JavaScript under the rule: 15 libraries in four languages. He confirmed
  it as his decision on 2026-11-19. In his words that day, spreading the libraries out was the
  decision to use, for each library, the language in which it is used most.
