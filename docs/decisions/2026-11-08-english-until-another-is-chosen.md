# The chat stays English until the user picks another language

- Date: 2026-11-08
- Proposed: the language was detected: a paste, or the first typed message, set the session's
  language.
- Decided: the page is English, so everything stays English until the user picks another language.
  A message or a paste in another language only makes the page offer it, once, with a button.
- Where: #12865, `docs/concepts/agent-network.md` ("Session language")
