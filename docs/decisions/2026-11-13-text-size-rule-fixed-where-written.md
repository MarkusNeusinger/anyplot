# The review's text-size rule is fixed where it is written, with no exemption for the chat

- Date: 2026-11-13
- Proposed: the rule VQ-01 asked for text legible at about 400 pixels wide, where the style guide's
  tick labels come out at about 5 pixels, so no plot that follows the style guide could pass. In the
  chat the contradiction cost users a second round.
- Decided: the rule changes where it is written: text size is judged in the full-size render,
  against the style guide's sizes. The chat gets no exemption, and VQ-01 still forces a repair there.
