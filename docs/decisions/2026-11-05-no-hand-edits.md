# A wrong plot is fixed in its spec or a rule and regenerated, not patched by hand

- Date: 2026-11-05
- Proposed: a plot can be patched in its code; the palette swap of May 2026 edited the plots' code
  across the catalogue.
- Decided: recorded on 2026-11-05 among the decisions the README names as his: a wrong plot is fixed
  in its spec or in a rule and then regenerated, not patched by hand, and a fix to a prompt or a spec
  reaches every plot it governs at that plot's next regeneration.
