# Each plot type has one library-agnostic spec, implemented in every library

- Date: 2025-11-19
- Proposed: the problem the vision names first: "Pick one library, then realize another was better".
- Decided: one library-agnostic specification per plot type, implemented in every library, so the
  libraries can be compared side by side; at the 1.0.0 launch the catalogue held 309 specifications
  in 9 libraries. He confirmed it as his decision on 2026-11-19.
- Where: `README.md`, `docs/concepts/vision.md`, `CHANGELOG.md`
