# The generator checks the Data block of new R, Julia and JavaScript files in its contract self-check

- Date: 2026-11-27
- Proposed: The rubric change of #14701 made the review's CQ-01 criterion score code structure only, so a JavaScript, R or Julia file without the Data block layout its library prompt mandates no longer lost a review point, and these languages have no adaptability checker of their own. A batch check had measured that a library-prompt line that no check enforces reaches about half of the regenerated files, and a checked one nearly all. On the table was a `data-block` rule in the generator's contract self-check, and the question whether it binds regenerations too: 6 of the 12 R and Julia regenerations of 2026-11-26 and 2026-11-27 that it judged had kept their predecessor's data code, as the generate prompt allows.
- Decided: He decided "Per Self-Check" and then "Nur neue Dateien": the generator's contract self-check checks the Data block of new R, Julia and JavaScript files and must fix it there. On a regeneration it only reports it, because his decision of 2026-10-23 keeps working data code in these languages. The review's record-only check lists it on every file. The session that built it settled the details: only what the spec's data shape needs, as the Python checker waives it.
