# Copilot reviews a pull request once, and again only after a high finding

- Date: 2026-10-23
- Proposed: any review round with findings drew the next request; a docs pull request had
  collected three rounds in one morning over wording.
- Decided: one Copilot review per pull request, and another only while the previous round found
  something high or critical whose fix was pushed. His reason: every round costs premium requests.
  Review on every push had been switched off on 2026-09-03.
- Where: #12250, `CLAUDE.md` ("PR Follow-Through")
