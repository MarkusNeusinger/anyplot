# Feedback comes from the site, first as GitHub issues, then through a quick widget

- Date: 2026-01-07
- Proposed: a request or a problem with a spec or an implementation is a GitHub issue.
- Decided: links on the site open such issues (2026-01-07), and from release 2.4.0 (2026-05-18) a
  feedback widget sits on every page. He confirmed it as his decision on 2026-11-19. His reason,
  given that day: at first the idea was to do everything through GitHub; then he realised that just a
  quick feedback would matter, because not everyone who uses the site has a GitHub account or wants
  the trouble, and since then more feedback has come in.
- Where: #3285, #7143, `CHANGELOG.md`
