# The public count follows the private list, and the privacy page says when a text is taken

- Date: 2026-11-18
- Proposed: the private list took only a finished text (two seconds without a keystroke, or the
  field left) and never one thrown away with the clear cross, Escape or "back". The public count of
  searches without a hit still fired after every keystroke, and the privacy page's row said only
  "when a gallery search finds nothing".
- Decided: the public count follows the same rule as the list, although it gets smaller and is no
  longer comparable with earlier months. The row on the privacy page says when a text is taken,
  because no key sends it.
