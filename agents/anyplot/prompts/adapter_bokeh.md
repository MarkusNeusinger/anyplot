## bokeh: what replaces the matplotlib conventions above

This plot is bokeh. Where the rules above name matplotlib (`savefig`, `figsize`, `dpi`, `FuncFormatter`, `AutoDateLocator`, a `VQ-03` or `VQ-06` gate line, the drawn texts the server checks), these rules apply instead:

- **The save.** The code ends on one protected statement, `with open(f"plot-{THEME}.json", "w", encoding="utf-8") as figure_file:` with `json.dump(json_item(p), figure_file)` inside, which writes the plot as JSON; the server draws it in a browser at the canvas, scaled so a 16:9 plot fills 3200 by 1800 pixels (a `figure(width=4800, height=2700)` at two thirds) and one narrower than 4:3 fills 2400 by 2400. Keep it as it is, the last statement of the file, and keep the `width` and `height` of the `figure(...)` calls: they fix how large the text is against the plot. It saves the name it names: to save several plots, put them in a layout (`row`, `column`, `gridplot`) and bind that layout to the same name last (`p = row(p, side)`). Never call `save`, `output_file`, `export_png` or `show`, never use `json` or `open` anywhere else, and leave `sizing_mode` unset: the server saves the figure, and the downloaded code gets bokeh's own PNG and HTML save back.
- **No render check of the texts.** A bokeh render has no probe, so the reviewer looks for each requested text in the image, and no gate counts labels or checks decimal marks: the code alone keeps them right.
- **Theme.** Colour every part from the theme tokens: `background_fill_color` and `border_fill_color` `PAGE_BG`, the title and axis labels `INK`, the tick labels and axis lines `INK_SOFT`, the grid `INK` at a low alpha, and `toolbar_location=None`.
- **Missing values.** `df` keeps a missing cell as `<NA>` or `NaT`. Drop the rows a mark needs before you build a `ColumnDataSource` or compute from them (`df.dropna(subset=[X, Y])`), so no category called `<NA>` and no point at a missing date appears, and hand integer columns over as floats (`df[Y].astype("float64")`).
- **Dates.** A `figure(x_axis_type="datetime")` draws every timestamp in UTC, an offset converted: write the axis with `DatetimeTickFormatter(days="%d.%m.%Y", months="%m.%Y", years="%Y")`.
- **Numbers.** BokehJS's formatters write English marks whatever their `language` (`NumeralTickFormatter(format="0,0", language="de")` writes `2,800,000`), so for a plot language with other marks put the ticks on fixed values and write their labels with the f-string swap above: `step = 10 ** math.floor(math.log10((high - low) / 5))`, `step *= next(factor for factor in (1, 2, 2.5, 5, 10) if factor * step >= (high - low) / 5)`, `ticks = [step * index for index in range(math.floor(low / step), math.ceil(high / step) + 1)]` from the column's `low` and `high`, then `p.yaxis.ticker = FixedTicker(ticks=ticks)` and `p.yaxis.major_label_overrides = {tick: f"{tick:,.0f}".replace(",", "_").replace(".", DECIMAL).replace("_", THOUSANDS) for tick in ticks}`. Value labels (`LabelSet`, `Label`) and tooltips take text you format the same way in Python; `en` keeps `NumeralTickFormatter(format="0,0")`.
- **Tooltips.** BokehJS reads a tooltip template and the value of each `(label, value)` pair as HTML, and escapes only the `@column` values it inserts. Put the data into the `ColumnDataSource` and name it with `@column` (`@value{0,0.0}`), never a Python variable's text (`("Server", name)` puts a cell's text into the HTML: use `("Server", "@name")`). A template holds only text tags (`div`, `span`, `p`, `b`, `strong`, `i`, `em`, `br`, `small`, `table`, `tr`, `td`) with quoted `style` or `class` attributes, fixed text, theme tokens (`tooltips=f'<div style="color:{INK}">@label</div>'`, the number formatted into a `label` column in Python as above) and numbers formatted with a numeric spec (`f"{limit:.2f}"`); a `style` holds no `url(...)`, no entity and no `@column`, and nothing takes `{safe}`. Write the tooltips list in one literal and assign it once.
- **Safe code.** Import only `bokeh.plotting`, `bokeh.models`, `bokeh.layouts`, `bokeh.palettes`, `bokeh.transform`, `bokeh.colors` and `bokeh.util.hex` besides the computing modules above. No JavaScript: never `CustomJS`, `CustomJSTickFormatter`, `CustomJSHover` or another `CustomJS...` model, `js_on_event`, `js_on_change` or `js_link`; no markup outside a tooltip (`Div`, `Paragraph`, `PreText`, an HTML label), no image or tile from a URL (`ImageURL`, `image_url`, tile sources, an `icon`), no private name (one with a leading `_`), and no bundled sample data (`bokeh.sampledata`).
