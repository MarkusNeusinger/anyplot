### Added

- **A decision log.** `docs/decisions/` holds one small file per decision
  the owner took that shaped the product, the pipeline or a public text:
  the date, what was proposed, what he decided and why, and the pull
  request. The code here is written by AI agents; what he contributes is
  direction, standards and push-back, which no diff shows. A rule in
  `CLAUDE.md` has every agent add the file in the pull request that carries
  a decision out, and one file per decision keeps open pull requests from
  editing the same lines. It starts with eight decisions of 2026-11-17 and
  2026-11-18.
